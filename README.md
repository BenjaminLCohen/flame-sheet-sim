# Flame Sheet Sim

Interactive three.js model of a premixed flame sheet in a Hele-Shaw channel:
wrinkling, cross-gap tilt, Markstein-law local burning rate, isothermal-wall
quench layers (Pe*), C² B-spline surface, and a live G-equation simulation
with an S_T/S_L histogram.

**Run it:** open `index.html` in any modern desktop browser (double-click works),
or `./serve.sh` and visit http://localhost:8000.

**Deploy it:** see `HANDOFF_GROK.md` — it is a static site, nothing to build.
